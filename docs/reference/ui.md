# Process Capability Analyzer UI

Defines the interface for the Cpk Analyzer, including sidebar inputs for
file uploads and parameter selection, and a main panel for data
visualization.

## Usage

``` r
ui
```

## Format

An object of class `shiny.tag.list` (inherits from `list`) of length 4.

## UI Components

This layout utilizes a Sidebar-Main structure. The sidebar handles data
ingestion and filtering, while the main panel hosts the interactive
DataTables and summary statistics.
